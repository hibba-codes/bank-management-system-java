# Smart Banking Management System 🏦

A simple console-based Java application that I built to practice core Object-Oriented Programming (OOP) concepts.

## 🛠️ Concepts Covered
* **Abstraction:** Used an abstract `Account` class as a blueprint.
* **Inheritance:** `Savings_Account` and `Current_Account` inherit common properties from the base class.
* **Polymorphism:** Overrode the `calculateInterest()` method to handle different behaviors dynamically.
* **Encapsulation:** Kept account data safe and private using getters and setters.

## 🚀 Features
* Standard banking actions: `deposit()` and `withdraw()`.
* Insufficient balance check logic.
* Automated interest calculation for savings accounts.
